免 Root 存档桥模式

推荐普通用户

无需解 Bootloader 锁或刷机，通过 PDSync 内置的自动化向导，为原版游戏 APK 集成专属存档通信桥并重新签名。

  • 零门槛安全：不改动 Android 系统底层与分区，原生系统无缝使用。
  • 自动化向导：只需提供游戏原版安装包，软件自动打桥并生成签名包。
  • 改版独立互不影响：每个改版拥有独立桥配置与通信信道。
⚠️ 安装前必读（防丢档须知）：
因签名证书改变，系统无法直接覆盖原版游戏，必须先卸载原有游戏。
卸载会导致原游戏本地旧进度被清空，请务必在打完当前这一局（通关或阵亡结算）后再卸载重装！

Root 原生接入模式

已 Root 设备推荐

如果你的设备已拥有 Root 权限（如 Magisk / KernelSU / APatch），PDSync 可直接授权原生读写游戏私有数据目录。

  • 完全无需卸载原版：保留手机内现有的一切正在进行的进度与历史记录。
  • 无需重新打包与签名：直接配合应用商店原版或官网原版游戏使用。
  • 极简一键授权：初次启动弹窗授权 Root 权限即可开启同步。
💡 极速无缝上手：
无需重新安装或打包游戏，当前正在进行的一局地牢冒险即可立即上传并无缝接力到 PC 电脑上！

FAQ

常见问题解答

解答你在安装、同步与日常游玩过程中的疑问

内置 WebDAV 和自建 WebDAV 有什么区别？赞赏是强制的吗？ +

赞赏完全自愿，绝非强制！

PDSync 对自定义 WebDAV（如坚果云、自建网盘等）提供完整、永久免费的支持。内置 WebDAV 是为了方便不想折腾网络配置的玩家而搭建的“开箱即用”服务。由于云服务器带宽与数据存储有持续的硬件租赁成本，我们通过赞赏机制来维持服务器收支平衡，所得款项仅用于服务器运维支出。

为什么 Android 免 Root 模式必须卸载原版游戏？本地进度会丢吗？ +

覆盖安装会导致签名校验失败，因此必须卸载，卸载会导致系统清除原版本地存档！

Android 系统的安全机制要求覆盖安装的应用必须使用完全相同的签名证书。免 Root 方案必须给 APK 注入存档通信桥并重新签名，这导致签名与原版不一致，无法直接覆盖，必须先卸载原版。

请特别注意：卸载会导致系统自动删除原版游戏内部的存档。请务必在打完当前局（通关或阵亡结算）后再卸载重装。如果手机有 Root 权限，使用 Root 模式则完全不会有这个问题。

这个工具能用来搞 SL（反复读档重来）吗？ +

PDSync 的设计目标是跨设备存档接力与意外容灾。虽然技术上存在历史快照，但我们非常不提倡将其作为 SL 手段。《像素地牢》的精髓正是随机性与死亡惩罚，频繁 SL 会让通关索然无味，失去游戏的原本乐趣。

点击“恢复”会把本机现有的存档冲掉吗？ +

在恢复写入前，PDSync 会先对本地当前存档做一个独立备份。如果云端和本地存在修改时间分歧，软件会弹出清晰的对比弹窗，由你确认是保留云端还是保留本地，绝不擅自冲掉任何数据。

上传按钮为什么显示灰色不可点击？ +

常见原因有两个：

  1. 本地当前存档内容与云端最新记录完全一致（内容哈希相同，无需重复上传）。
  2. 尚未启动过游戏，本地尚无任何存档文件（请先进游戏走动两步并正常保存退出）。
恢复完成后启动游戏，怎么还是原来的老进度？ +

请确保在点击“恢复”前已经彻底退出/关闭了游戏进程。如果游戏一直在后台常驻，其内存中的旧进度会在退出时再次写回磁盘，导致刚恢复的文件被覆盖。

桌面便携版 (Portable) 的配置保存在哪里？ +

为了避免覆盖更新时丢失配置，桌面端所有配置及运行记录默认保存在当前操作系统的用户目录下（~/.pixel-dungeon-sync）。更换便携版程序无需重新设置，升级时直接解压替换主程序即可。
