# 本地交互原型

独立 HTML/CSS/JavaScript，不改正式 Compose 或同步逻辑，无依赖、CDN、真实网络请求。

从此目录运行已有 Python：

```powershell
python -m http.server 8766 --bind 127.0.0.1
```

浏览器打开 `http://127.0.0.1:8766/`。页面使用 ES modules，需要本机静态服务，不使用 `file://`。
修改页面后刷新即可，无需 Kotlin 构建。验证状态逻辑：`node model.test.mjs`（49 项 Node 内置测试，无依赖）。

引导分四步：选择游戏 → 设置存档路径 → 配置 WebDAV → 完成/选择进度。第二步预填当前样本的 Windows 默认目录（模拟用户 C:\Users\Demo），允许编辑。进入时及路径编辑稳定 400ms 后就地模拟检查，显示“游玩 X 次 · 存档 Y 个”和各槽位示例修改时间。下一步复用有效结果，检查未完成时等待它完成后进入 WebDAV；失败留在原处可修改或重试。空路径不能继续。返回保留同游戏路径，更换游戏重置默认路径与读取结果，修改路径和返回会取消未完成检查。

“选择其他存档路径”打开页面内模拟选择，确认使用 D:\Game Saves\<样本标识>，取消保留原值；不调用文件上传或实际目录 API。

正常体验按引导操作。展开产品界面下方独立的“原型测试”可切换双方为空、单边存档、冲突、相同进度、连接失败、连接中、游戏运行等场景。切换场景会重置模拟状态。
另有“读取中”和“读取失败（重试可恢复）”场景；除主页历史演示外，其余场景均从第一步开始，进入对应步骤时体现模拟效果。
路径设置版通过逻辑测试和本机 Edge 的编辑、返回、文件夹取消/确认、空路径校验及失败重试验证。

只使用示例数据：密码不读取、不保存；游戏选择只模拟示例名称，不打开真实文件。
上传、恢复、连接仅在内存中演示，页面 CSP 禁止连接请求和表单外部提交。
引导与主页共用覆盖确认弹窗：本机有不同存档或游戏记录时，说明来源设备及不保留本机备份，取消或 ESC 不变更；确认后仅模拟覆盖。确认绑定当前内容与选择，变化后旧确认失效。确认本机完全为空则直接模拟恢复；内容版本相同显示已同步并禁用重复同步。关闭或刷新即丢弃模拟状态。正式 Compose 的备份逻辑未在本次修改。
用户确认交互后再移植到 Compose，此原型不是正式同步客户端。

已在 Windows 本机 Edge 实际点击空状态完成、冲突选择、主页上传/恢复与取消、同页设置返回、连接失败、连接中取消、两种单边存档及游戏运行阻止操作。两种单边流程也在 390px 视口检查，无横向溢出；浏览器尺寸验证后恢复。浏览器控制台未发现错误。未触碰正式同步器或真实数据。

折叠测试区可切换四个英文游戏名称样本及名称缺失场景。名称/版本使用已检查 Manifest 的固定数据，不解析或上传 JAR，不表示正式支持这些改版。更换后清除读取结果，四步、主页及设置沿用同一名称；缺失名称显示“未命名游戏”。

游戏信息卡：四个本机样本均静态取桌面启动器使用的 `icons/icon_128.png`（128×128 原始 PNG），不执行 JAR。来源与 SHA256 见 `sample-sources.json`。Manifest 无可信作者/更新日期，不显示这些字段，也不使用 ZIP 时间。图标许可及署名要求无法从现有离线样本确认，故只放在被 Git 忽略的 `.local-icons/`，不随仓库发布。其他检出或资源加载失败显示中性占位；本机四个图标可正常预览。未新增网络下载。

状态样本独立保存总游玩次数、槽位列表和文件数量：多槽为游玩28次、2个槽位（17个文件），仅记录为游玩12次、0槽（3个记录文件），全空为0次、0槽。仅记录仍属于待同步数据，不进入双方完全空分支。检查中、失败和待检查不伪装成零。示例修改时间为固定本地格式，非扫描时间，不解析真实排行榜或存档。

WebDAV 第三步：“测试连接”仅模拟测试，成功留在本页，再点“下一步”进入比较。未测、测试中、失败和任意输入变更均不能前进；键盘提交只触发测试。空密码允许测试，不读取或持久化密码值。编辑、返回和场景切换使过期异步结果失效；离开后重新进入连接页重置为未测试，避免已清除的密码与旧成功结果混用。


主页默认展示“多设备存档历史”模拟场景：固定“云端存档”和“本机”两列，设备节点与云端副本分别展示，连线只取实际 parentIds；上新下旧。节点用按钮支持键盘选择，明确高亮并可清除。窄屏仅历史容器横向滚动。
未选择时以 publishedOrder 选取最新可用云端内容，不以存档时间或本机未上传节点决定。显式选择旧云端节点可恢复；仅本机节点显示原因并禁用恢复，不悄悄回退。确认绑定实际目标的内容、设备和时间。恢复从选中的云端节点新增本机接收节点，并移动本机当前标记；云端历史保持不变。上传从本机节点新增云端副本，上传及恢复分别用方向连线表示。已有历史节点不改写。
所有设备、时间、关系、内容标识均为虚构内存样本，未接入真实数据。49 项状态测试覆盖历史选择与原引导回归。

时间轴规则：云端列固定为第一列；所有节点统一按界面显示的 time（存档内容时间，固定 YYYY/MM/DD HH:mm 格式）降序排列。上传和恢复保留该时间，不使用发布顺序或操作顺序排序。相同时间按稳定节点 ID 分配行，不同列可同排，同列另排以免重叠；连线用节点 ID 查找新位置。默认恢复仍独立按 publishedOrder 选最新可用云端内容。

历史树仅展示两列：左侧云端存档，右侧本机。所有来源设备的云端副本保留来源名；本机只显示有限历史：空、一个已同步节点、或同步基线加黄色未同步当前节点。未同步节点连接本机基线，基线连接实际对应云端；首次本地进度无基线时只显示黄色节点。上传或恢复后归并为一个已同步节点。先过滤可见节点再排列时间行和生成连线，隐藏的其他设备本地节点不产生空行或悬空连线。

云端分支只使用明确的 cloudParentIds 连线，不根据时间相邻推断关系。节点支持行内命名、保存和取消，最多40个 Unicode 字符；空名恢复默认、重名允许、特殊字符按纯文本显示。名称保留设备/时间信息，不改变内容、同步状态、排序或恢复目标；仅存在当前页面内存，刷新丢弃。

直线箭头依据副本来源：上传本机→云端，恢复云端→本机，云端父→子，本机基线→未同步当前进度。箭头使用同色固定尺寸，距目标卡片5px；不根据屏幕位置推测传输方向。

恢复入口回归覆盖默认、显式最新/旧版、命名后、上传后的副本ID、相同内容禁用、取消及重复点击。所有展示的云端样本均可恢复；默认主页最上方云端节点与默认恢复目标均为 save-4。已移除人为不可用样本及其专属提示。真实同步核心的错误处理未改动。
