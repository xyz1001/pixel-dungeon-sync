# v6：单窗口引导页面（2026-10-09）

## 范围

保留一个顶层Compose Window。首次连接、主页、连接设置、冲突选择与操作确认都是同一窗口内的页面，不再使用DialogWindow或AlertDialog。连接页仍仅有地址、用户名、密码和一个“连接”提交；失败保留输入，错误/操作固定在滚动区之外。设置页取消返回原主页，丢弃未提交改动，并保留主页历史选择和滚动状态。

点击操作时的退出游戏/暂停其他同步确认也改为同窗口页面；忙碌期间尝试关闭主窗口只显示页内提示，不产生第二个窗口。唯一保留的独立标准文件选择器是用户显式选择目标JAR时的JFileChooser；它不用于连接或操作确认。本轮不实现Android，不声称已经完成Android适配。

## 生命周期保护

- 启动阶段的本地档案读取与可选安全密码读取/只读连接检查串行执行，并持有同一个connectingAtStartup保护，不能由一个旧加载完成回调提前释放另一项工作的busy状态。
- 页码/代次拒绝旧页面的完成回调。返回、连接和确认操作同时检查启动/进行中状态。
- ConnectionPageLifetime同步预留单次尝试，重复点击不能产生第二次连接；取消/移除页面使旧尝试不能再次保存配置、写凭据或完成为新页面结果。
- 保存区与页面关闭在同一锁下线性化。已经开始的安全存储/配置写入先完成，关闭随后生效；不承诺瞬时取消或撤销已经开始的外部操作。正常按钮与主窗口关闭在工作进行中被阻止。
- v5的安全MKCOL、既有profile保留、自动只读检查及密码授权行为不变；快照、DAG、恢复和游戏存档逻辑没有改动。
