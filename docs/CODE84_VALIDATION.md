# code84 / 0.5.63-test

用户授权将主页已到期状态移到原“存档待检查”状态位置，并增加该区域的赞赏按钮。到期且当前官方身份已确认时显示原“服务已到期”文案和既有风格赞赏按钮，打开已有赞赏页；其他正常状态保留。独立notice里的旧到期完整行去重，其他错误和操作反馈保留。

Android之前仅将到期状态作为临时notice，导航统一清空导致提示消失。现在使用现有按身份隔离的期限显示缓存重建状态，同boot、当前身份及单调时间有效才显示。进程重启可恢复同boot记录，系统重启/未知boot/缺服务器时间/未知期限/禁用/无限期不据旧记录推断到期。续期返回的新记录替换后旧状态消失。缓存只显示、不授权；按钮每次点击重核页面、身份、状态，旧回调不能跨账号或页面执行。

Android和Desktop共享主页UI同步，登录、存储时机、同步gate、服务器不改。本轮新增UI仅限明确授权的主页赞赏按钮；游戏管理说明来源不一致仅记录，不修改。离线检查不代替断连期间的真机回归。冻结后结果以最终验证单为准。
