# 默认存档位置、连接向导与安全密码存储

日期：2026-10-08。接续 fcab2c0 自动版本里程碑。本轮仅在 dot 云端工作，没有访问 Windows 用户电脑或 Mac，没有 push。

## 实现

- 官方 Shattered 4.0.2 默认目录规则，OS/home/env 依赖可注入，未来游戏可替换路径适配器。主界面路径只读，缺目录明确报错，旧任意 root 不具权威；不静默切到演示/工作目录。
- 首次启动两步连接向导：WebDAV 地址、账号、密码、档案与 GET 连接测试，然后可选目标 JAR。取消不写配置或凭据，返回前一步保留草稿；修改后原测试证明失效。测试成功也不会自动保存。404 仅说明缺 head，不冒充已验证写权限。
- 主界面为存档状态、同步/备份与历史；完整连接字段不常驻。设置中编辑 endpoint/username 会立即清空旧连接密码，防止发往新服务。启动自动取密码/测试期间禁用交互，防止旧连接结果覆盖新设置。
- 恢复沿用逐局版本校验、先备份、二次停止/变更检查、待上传阻止恢复、显式冲突选择。401/403 清除内存连接状态并重新提示密码，不丢失冻结上传和历史。
- ConfigFile 保存安全白名单，原 saveRoot/version 配置在改写前保留原字节备份。不碰旧历史目录；不同物理目录不共用基线/队列，同一目录沿用既有 scope。
- Windows Credential Manager、macOS Keychain、Linux Secret Service 安全存储适配。私有 stdin 传密码，参数只含固定程序/脚本与专用 scope hash；不创建明文/自制加密后备。地址+用户名精确分域；不列举用户其他条目。读取结果/错误诊断不输出秘密。取消没有凭据写入。
- 保存成功才将 rememberPassword 持久化为 true；不可用时保留当前会话并可见提示。取消勾选保存删除同一规范化连接条目；Linux 额外验证锁定条目未遗留。凭据写入后若配置失败，明确提示系统密码已更新、配置未保存，避免误称无副作用。
