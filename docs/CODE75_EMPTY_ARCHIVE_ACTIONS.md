# code75 / 0.5.54-test · 空存档操作保护

主页既有“上传到云端”“恢复到本机”按各自来源是否有可用存档启用。双方空时两按钮均禁用；仅本机有档允许上传；仅云端有有效档允许恢复。目的地空不阻止有效方向。已同步内容仍沿用既有无需重复操作判断。

共享 `SharedHomeArchiveAvailability` 只读取宿主当前核验过的完整文件映射与云端图，不依据状态文案、时间、名称或可见历史分页判断。未知/失败/未核验/未完成云端图不授权操作；明确选择失效不退回另一份存档。多分支保留现有分支选择流程。有效方向决定既有推荐标记，空云端不再显示推荐恢复。

Android 显示能力、保留回调和直接主页请求入口采用同一保护，并绑定实际观察的账号、游戏、后端、inspection 与 history 身份；恢复确认再次检查所选存档与观察身份。Desktop 同步采用来源判定与当前观察保护，保留有真实冻结来源的待上传重试。

不新增控件或提示，code74 读取浮层、code73 输入框、既有恢复确认与取消保持。没有访问真实云端凭据或存档，没有执行真实上传/恢复。

验证通过生产 Compose 离屏渲染与实际指针派发检查禁用操作，另以宿主单元/执行回归检查读取、失败、过期选择与状态变更。此证据不等同 Android 真机安装后的行为或 Windows 实机运行验证。
