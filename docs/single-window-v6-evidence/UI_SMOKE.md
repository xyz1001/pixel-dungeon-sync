# v6 单窗口原生 UI 冒烟

2026-10-09 UTC，结果：下列范围通过。使用已完成全量构建的本轮桌面/核心 JAR，以及之前已缓存的运行时依赖，在 dot 云端 Linux 的两个全新隔离 HOME、XDG_DATA_HOME 和 pdsync.workspace 中运行。只使用 loopback 演示服务与公开 demo 测试账号。没有用户电脑、真实凭据、生产 WebDAV 或真实存档。

## 实际运行步骤

1. 首次启动直接在唯一主窗口内显示地址、用户名、密码和“连接”，没有连接子窗口。原生窗口边缘缩小至外框约 761×640、客户区 751×606，三字段、取消和连接仍可见。
2. 点击“取消，返回主页”，在同一个根窗口显示主页。文件及服务检查确认没有 config.json、网络请求或创建的应用目录。
3. 从主页设置返回连接页，填写本机 `http://127.0.0.1:8779/dav-root` 和 demo 测试账号。对“连接”执行一次原生双击；服务记录显示仅有一个根目录检查请求，未触发第二次连接。
4. 受控服务暂时延迟该请求。在此期间使用系统 Alt+F4 请求关闭：原窗口仍在、顶部出现内联等待提示，连接页保留，取消和连接按钮禁用。没有额外对话框或新的应用窗口。取得截图后释放服务响应。
5. 服务根事先存在，shattered/default 两级应用目录不存在。单次连接只对这两个缺失目录执行 MKCOL，逐个回读确认，检查旧协议标记并读取完整档案列表。随后原根窗口直接进入主页，显示已连接；没有第二次保存步骤。
6. 主页进入设置页，更改用户名但不连接，点击取消返回主页，再次打开设置。原地址、用户名 demo 以及该连接的会话密码恢复；未提交的用户名丢弃。config.json 与取消前逐字节相同，服务根请求数仍为 1。
7. 主界面左侧滚动后进入“创建本地快照”的确认页。确认页在同一个根窗口中。勾选两个确认框后点击取消，再次打开确认页：两个复选框重新未选中、确认按钮禁用。没有创建历史/备份/待上传 ZIP，也没有网络请求或游戏文件改变。
8. 空闲时 Alt+F4 能正常关闭，窗口清单中的应用根窗口变为 0。
9. 第二个隔离环境预置 profile=legacy-kept42 的既有配置。启动仍只有一个根窗口。故意输入错误演示密码，HTTP 401 在页内显示，草稿保留；没有写配置或创建目录。更正密码并连接后，只创建缺失的 legacy-kept42 子目录，保留已有 profile ID，成功进入同一根窗口的主页。
10. 第二个实例空闲时正常关闭，应用窗口再次归零。两个隔离游戏目录前后逐文件 SHA-256 与原测试副本一致；未执行 PUT、DELETE、MOVE 或上传存档，配置中没有密码。
