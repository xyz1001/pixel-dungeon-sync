# code74 / 0.5.53-test · 主页读取浮层

仅新增用户要求的主页存档读取浮层：半透明遮罩、M3 同色圆角面板、圆形进度指示与“加载中…”。沿用共享 Compose 主页，不另开窗口，不新增关闭/取消/刷新按钮。

`SharedHomeState.archiveLoading` 与通用 `busy` 分离，仅当前主页显示。读取期间主页全部操作禁用，指针事件被遮罩接收，辅助功能只提供加载内容；完成后恢复既有页面。

Android 将实际 `readComparison` 读取和已有自动历史刷新状态接入。读取不增加请求；手动路径保持既有操作锁，自动路径沿用账号/所选游戏和页面代次校验。Desktop 使用独立读取票据集合，跟踪本地档案、云端和实际历史重读；不同票据各自完成，旧页面完成不能清除新读取。定时文件变化观察仍静默，不让普通上传/恢复/启动 busy 误显示读取浮层。

成功、失败与取消均通过 finally 释放；离开主页/销毁或过时结果不可保留浮层。UI 不解析状态文案来猜测加载状态，也不使用最短时长或假加载定时器。

保留 code73 框内摘要及密码眼睛、code72 导出按下反馈、code70 全高布局、code65 取消恢复；不恢复已删除接入底部提示。

验证使用生产 Compose 离屏渲染与真实指针派发，覆盖窄/宽视口、双倍字号、空/已有档案、重复点击、读取完成、普通忙碌与离开页面。两端宿主生命周期与并发测试使用隔离状态/协程与源码契约；不等同于 Android 实机 Activity、真实慢网或 Windows 实测。未登录真实账号或写云端存档。
