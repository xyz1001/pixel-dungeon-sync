# code81 / 0.5.60-test 开发交付验证

日期：2026-10-20。基于完整已交付 code80 修复客户端。服务端仍需独立批准上线；本轮没有部署或修改真实账号。code81 已撤回 code80 的外部原生 token/Bearer 路径，恢复完整 code79 的登录与 Basic 期限协议，无需开放新接口。已达到原生到期时间的旧账号仍待另外批准的期限映射生效。

## 根因与范围

- Desktop 的已保存连接恢复和四个远程执行入口直接构造 DAV，未重新读取真实服务期限。
- Android 只在恢复路径检查期限，缓存 facade 和自动监听可能跨越期限继续使用。
- 每次新的远程操作重新获取可信 entitlement；每个 DAV 请求及 HTTP 重试前使用本地期限租约检查，不逐文件进行密码认证。缓存显示不能授权同步。
- 官方 origin 的旧路径、误标 provider 和规范化域名别名也必须受限。无关自定义 DAV 不受官方账号规则影响。
- 已确认到期显示现有过期状态；网络失败、无效响应与时钟异常拒绝同步但不据此认定已过期。续费后的可信新期限可恢复操作。
- Android 的租约使用包含深度睡眠的 elapsedRealtimeNanos；Desktop 以单调时间计算服务端剩余期，本地墙钟只用于发现休眠/时间跳变并保守拒绝，不据此宣称过期。每次请求发送前检查，不声明撤销已经提交的远程写入。
- 本地恢复、归档、命名等不依赖在线权限；成功后的云刷新失败单独记录，保留本地成功结果。
- 设置行仅将动作标签“暂停自动上传”改为“暂停”/“Pause”；已暂停状态、启用动作和无动作行保持原语义。未增加控件或提示。
- 未改变 code80 服务端一年宽限映射。旧未迁移账号没有标记时不能减一年；无限期仍由受验证的无限期限字段表达。
