# code73 / 0.5.52-test · 凭据输入

范围：仅用户明确要求的简短框内提示、密码显示/隐藏按钮，以及输入状态保留加固。

- 删除 code67 的框下长篇规则；空字段以不可编辑 placeholder 显示规则摘要，开始输入后隐藏。提示不进入用户名、密码、请求或持久化值。
- 内置账号注册用户名仍以服务端真实规则 `[a-z0-9]{3,32}` 校验；注册密码仍按 6–128 Unicode code points、控制字符/代理项与前缀限制校验。登录沿用原凭据规则，不因注册摘要改变。WebDAV 使用服务商凭据，不增加密码长度限制。
- 密码默认遮罩，眼睛按钮切换显示。按钮使用现有 Material filled 图标体系，辅助功能名称为“显示密码”/“隐藏密码”。可见状态只在当前组合内记忆，不持久化；变更身份/服务后重置。
- 输入控件显式保留 TextFieldValue 中的 selection/composition。控制器回传相同文本时不重置编辑状态；只有外部真正变更文本时才更新（例如用户名更改触发旧密码清空）。
- 密码显示和隐藏都保持 KeyboardType.Password；不改普通文本类型，不绕过系统安全输入法。FLAG_SECURE、日志脱敏和凭据存储逻辑不变。
- 保留 code72 导出按钮按下背景、code71 位置、code70 全高、code68 APK 名称/图标，以及 code66/65 既有行为。

## 证据边界

用户手机的 code72 实际默认百度输入法、密码字段切入 OPPO 安全输入法。ADB 数字事件前后焦点与输入会话序号不变；该证据无法操作安全输入法的软键盘数字布局切换。因此目前未证实“每字符重建字段/重启输入法”为该手机现象的根因。

本版对编辑状态的稳定性进行加固及回归；不会将普通 Compose 重组当作已确认根因，也不宣称等价于 OPPO 安全键盘的软数字布局实测。最终验证报告区分生产 Compose、AOSP 模拟器和该手机实测范围。

本次 API36 TCG 模拟器在 Android 开机阶段出现 system_server 重启，未达到 boot_completed；基线 APK 尚未安装，软键盘布局测试未运行。生产 Compose 输入会话、焦点、选区、组合态测试不依赖该模拟器，独立执行。
