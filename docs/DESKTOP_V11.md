# 正式桌面界面与隔离验证

## 四步引导

1. 识别游戏或使用系统 JAR 选择器。不运行游戏。
2. 默认填充系统存档目录，可手动编辑或使用系统目录选择器。显示实际进行中槽位、各局文件修改时间和 rankings.dat 的 total；缺少或无法解析的记录显示未知。仅点击下一步才创建缺失的专用空目录。
3. WebDAV 三字段，密码可空。测试通过后才能点击下一步；编辑字段或再次测试会失效旧证明。测试会准备应用自己的同步目录，下一步才保存本地配置。
4. 比较真实内容。双方空可完成，相同内容可采用关联；空目标恢复无需再次确认。有独有本机内容才明确选择覆盖或取消，取消不执行操作。

新选择保存在 selectedSaveRoot，旧 saveRoot 不静默恢复。设置页在同一窗口内修改路径、游戏和连接。Windows 使用系统 FolderBrowserDialog，macOS 使用系统 choose folder，Linux 使用已有 zenity；选择器不存在时明确提示手动填写路径，不安装依赖。JAR 选择仍使用 AWT 原生 FileDialog。

## 真实双列历史

云端在左、本机在右。云端节点来自已校验提交缓存及完整父 DAG；不生成示例节点。每页最多 20 个云端节点，较早历史可翻页并选择恢复，翻页不会下载快照。显式恢复时重新核验提交和实际对象。

本机无存档为 0 个节点，干净基线或无基线当前内容为 1 个；有基线且当前不同为 2 个。未同步当前内容为黄色，基线到当前为虚线。父提交关系及有实际记录的上传／恢复使用直线，中点箭头指向结果。旧基线缺少传输方向记录时不猜测跨列箭头。没有左侧时间轴或清除选择按钮。未手动选历史时跟随唯一云端 tip；并发分支不按时间擅自选胜者。

当前命名写入目录 sidecar，随下一份上传快照同步。历史节点的本机显示名称单独持久化，界面明确标注不会修改不可变云端记录。

## 内容保护与身份

本机内容为空或存在完全一致且已验证的云端副本，历史恢复无需重复确认。普通 tip 恢复继续要求干净基线和祖先关系。独有内容的覆盖确认绑定当时文件集合；恢复前稳定采集再次检查，变化则停止。历史恢复生成以真实当前基线为父的新操作，原云端记录不删除。


恢复已验证快照自动继承其 runUUID；相同内容和重启保留原身份。正常上传不弹身份确认。同步器未观察期间内容变化无法证明同局连续性时，身份维护仍可处理未知身份，用户可选择“同一局继续”或“新的一局”。不通过种子、槽号或摘要生成伪造的连续身份。

## Windows 验证

使用已有 JDK 21.0.12.1+1、Gradle 8.14.3 缓存，所有 Gradle 调用带 --offline。临时合成档案和内存 AppendStore 验证历史恢复权限、0/1/2 本机节点、分支默认选择与真实父关系。正式 HistoryChart 使用实际隔离会话生成的图执行离屏渲染及云端节点选择／命名点击；渲染结果位于 desktop/build/reports/history-chart.png。

原生生产入口仍用独立 HOME、user.home 和应用状态启动验证；无真实账号、真实存档、实服传输或新工具下载。Windows 系统目录选择器未进行人工选择验收；macOS/Linux 原生运行和选择器不可用时的系统表现未在这台 Windows 执行。离屏点击测试不等同于完整 Windows 人工验收。异常回滚不等同于任意断电下的原子恢复。

最终结果：core 426 项、desktop 63 项，共 489 项，484 通过、5 跳过、0 失败。完整回归日志为工作区 desktop-v11-preflight-tests.log；最后一处祖先槽位修正另经 desktop-v11-lineage-tests.log 的核心全量回归通过。生产窗口复验输出 PDSYNC_UI_SMOKE_OK 1120x800，错误日志为空，探针自行退出。Windows FolderBrowserDialog 已验证可实例化，未进行人工选目录点击。

131 已移除存档合并动作和专用算法，覆盖与取消继续使用现有确认流程。旧合并验证不代表当前支持功能。
